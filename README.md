## Selected Work

**[CleanData with LLM](https://github.com/momofahmi/CleanData-with-LLM)** - Repairing distribution-level errors in tabular ML data with a hybrid statistical-LLM agent. Benchmarked statistical, LLM-only and hybrid modes across **72 runs and four datasets** using a leakage-aware 60/20/20 evaluation protocol.

**[BESSTIE](https://github.com/momofahmi/NLP-sequence-classification)** - Semester-long team project on sentiment and sarcasm classification across UK, Australian and Indian English. Led the integration and evaluation of **five model configurations** using LLaMA 3.2 with LoRA and RoBERTa; the UK sentiment model achieved **0.951 mean macro-F1 across two seeds**. [Live demo](https://huggingface.co/spaces/momofahmi/besstie-cw-nlp).

**[Financial AI](https://github.com/momofahmi/Financial-AI)** - Company financial-data management and forecasting. Developed backend features with Node.js, Express and MongoDB, integrated Excel ingestion and Python-based LSTM forecasting, and later coordinated delivery as Project Manager.
